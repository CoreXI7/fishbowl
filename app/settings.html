Look & feel

Browser tab icon A square PNG works best. Default: the bubbles.

Mascot (optional, left column · Bubbles theme; other themes have their own below)

PNG, JPEG, WebP or GIF, up to 2 MB. A transparent PNG looks best.

Themes 🎨 on the dashboard (or T) switches; each browser remembers its own pick

Each theme can have its own mascot and lines. Leave a field empty to use the theme's built-in default (shown faded). Picking a tab previews that theme on this page.

Services

Found automatically from Nginx Proxy Manager. Group them, rename them and pick icons. Icons are names from dashboard-icons (e.g. plex, sonarr); leave empty to use the site's own favicon. Services you haven't grouped show up under "New / other" on the dashboard.

Extra services not in NPM

Anything else you want health-checked: a NAS, a router, a box on another network.

Integrations

Keys are stored on the server and never shown again (you'll only see "saved"). Changing an address means typing its key again, so a key can't be sent to a new server by accident. Test checks what's saved, so save first.

Security

Fixed settings change these in docker-compose.yml / .env

These protect the dashboard itself, so they can't be changed from a web page.

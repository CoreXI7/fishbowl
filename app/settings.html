Themes

What every browser shows until someone picks another one with 🎨 (or T) on the dashboard. Each browser remembers its own pick.
The drifting bubbles and effects, in every browser that hasn't switched them with 🫧 (or M) on the dashboard. "Follow each device" leaves them off for people who turned animations off on their phone or computer.

Edit a theme

Each theme's mascot, tab icon and what it says. For Miku and Gura, an empty field uses the theme's own text (shown faded). Picking a theme here only previews it on this page; the default is set above.

Services

Found automatically from Nginx Proxy Manager. Group them, rename them and pick icons: an icon is a name from dashboard-icons (like plex or sonarr), or leave it empty for the site's own icon. Services you haven't grouped show under "New / other" on the dashboard.

Services not in NPM

Anything else you want health-checked: a NAS, a router, a box on another network.

Advanced
For services on a Docker network the dashboard isn't on: it asks your reverse proxy instead, the way a visitor would. Write the host name. Add a path that skips the sign-in (vault.example.com/alive) when / is behind one: otherwise the sign-in page always answers, and the service looks up even when it's down.

Integrations

Each address must be one the dashboard's container can reach: a container name on a Docker network it shares, or your server's LAN IP and port. Keys are kept on the server and never shown again. Changing an address means typing its key again, so a key can't be sent to a new server by accident. Test uses what's saved, so save first.

Drives & hardware

What the collector on the host measures. These apply within a minute of saving.

Security

Your known IPs: logins from them aren't flagged. A full address, or a prefix ending in a dot (192.168.1.) or a colon (2001:db8:). SSH and sign-in logins from anywhere else are flagged red (this needs the collector). It doesn't let anyone in. The list stays on the server.

What the collector watches

Switches and choices apply within a minute of saving. Files and patterns marked needs your OK on the host wait until you approve them there, because the collector runs as root.

Backups

How the collector tells whether your backups ran: it reads your backup script's log and looks at the files the backups leave behind. Shown on the Security & backups card and its Backups view.

Files and patterns here wait for your OK on the host after you save (the overdue time applies by itself).

About

These are set in docker-compose.yml (or .env) because they protect the dashboard itself, so a web page can't change them. Change them there, then run docker compose up -d. Every setting is described in docs/SETTINGS.md.

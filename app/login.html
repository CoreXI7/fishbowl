Type the 6-digit code from your authenticator app. Lost your phone? Type one of your recovery codes instead. Lost both? On the server, docker exec -it <container> python /app/auth.py reset deletes the account (settings and keys stay) so you can create it again.

Create the account that signs in to this dashboard. To prove it's you setting it up, you need the setup code from the container's log:

docker logs <container> 2>&1 | grep "^SETUP CODE" | tail -n 1
Like ABCDE-FGHJK-LMNPQ-RSTUV-WXYZ2. A new one appears in the log every time the container starts: only the newest works. (After auth.py reset or setup-code: the one that command printed.)
At least 15 characters. A few random words are easy to remember and hard to guess. Your password manager can make one.
